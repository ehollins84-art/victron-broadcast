victron-broadcast

Flash your ESP32-S3 from this page — no installs. Works in Chrome, Edge, and the Chromebook built-in browser.

Your browser does not support Web Serial. Open this page in Chrome or Edge. (On a Chromebook, the built-in browser is Chrome.)

1. Flash the firmware

  1. Plug the ESP32-S3 into your Chromebook with a USB-C cable that supports data (not charge-only).
  2. Click the button below and pick the device that looks like USB JTAG/serial debug unit or CP210x.
  3. Click Install → victron-broadcast (latest) → Erase device + install.
  4. If it can't connect, hold the BOOT button while you press RESET, then release RESET (release BOOT after the install starts).
Your browser doesn't support Web Serial. This page must be loaded over HTTPS. Chip should be ESP32-S3. Erase + install takes ~30 seconds.

2. Configure it

  1. After install, the ESP32 reboots into setup mode and creates a WiFi network called victron-broadcast-setup (open, no password).
  2. From your Chromebook's WiFi menu, join that network. ChromeOS will pop a "Sign in to network" page automatically — click it. (If not, open http://192.168.4.1.)
  3. Fill in: WiFi credentials, InfluxDB URL/org/bucket/token, and one row per Victron device. Tap Scan nearby and the page lists every Victron device in BLE range so you only need to paste the 32-hex bind key from VictronConnect.
  4. Tap Save & restart. The chip leaves AP mode and joins your real WiFi.

Need to start over? Hold the BOOT button on the chip for 3 seconds while it's running — it wipes config and goes back into setup mode.

3. View the dashboard

  1. Sign up free: InfluxDB Cloud Serverless & Grafana Cloud.
  2. In Grafana, add an InfluxDB data source pointing at your cluster URL, then import dashboards/victron.json from this repo.
  3. Dashboard settings → Public dashboards → enable. Share that URL anywhere.
